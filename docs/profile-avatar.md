# 头像上传与资料保存

头像沿用真实 `media-upload` 图片处理服务和私有 `fishing-media` 桶。客户端裁剪后仍经过服务端解码、重新编码和文件检查，不接受用户提供的远程头像 URL。原片不被修改。

选择、裁剪和上传只形成候选头像；点击「保存资料」才通过 `update_profile` 的可选 `avatar_id` 同事务保存。省略该字段保留原头像，传 `null` 恢复默认头像。上传或保存失败保留当前输入，切换账号或关闭页面会取消迟到结果。

`media_assets.avatar_profile_id` 是唯一头像归属，只能等于资源作者，且资源必须为已验证图片。头像不能同时属于动态、日志、聊天、私密线索或钓点。公开资料返回 `avatar?: Media | null`；客户端通过现有签名服务取短期图片地址，不把服务器密钥或公开桶写入前端。

替换或移除已保存头像会删除旧图片索引，立即撤销后续签名资格，并交给已有 `media-cleanup` 队列删除对象。账号删除同样触发队列。未保存的候选仍是未绑定的私有上传，沿用草稿规则，不按年龄扫描删除。已下载的副本和未到期签名无法追回；拉黑会阻止新的头像读取签名。

H5 共享裁剪器支持鼠标／触摸拖动、双指缩放、点按居中、旋转、缩放按钮和键盘方向键，并在解码前检查字节数和图片尺寸。微信／原生保留平台裁剪分支，实际相册和触控需要设备验收。
