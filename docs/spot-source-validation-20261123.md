## 权限和数据边界

- 未带专用令牌的真实 worker 请求返回 401；普通公开 Key 和用户 JWT 不具备队列权限。
- 远端回读 `anon` 无领取、令牌校验权限，`authenticated` 无入队、完成核验权限；公开目录只展示已发布且未过期的记录。
- 专用令牌保存在 Vault，不写入前端、Git 或回读报告。`verify_jwt=false` 的 worker 自行校验此令牌，不向用户开放抓取地址或批量参数。
- 标注修改使旧租约失效；同名不同 POI 不覆盖已有记录；查询简称相同但真实 POI 不同的地点也不会误合并。最后一项先复现失败，再通过补丁与回归测试。
- 安全顾问未新增 WARN/ERROR。项目原有的“泄露密码保护未启用”提示仍存在，与本轮来源采集无关；可参考 [Supabase 密码保护说明](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)。
