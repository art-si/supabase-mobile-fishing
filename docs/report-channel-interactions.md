# 上报渠道与邮件交互

## 全国受理与系统接入方案

2026-11-21 核对。钓友集对疑似电鱼、毒鱼、炸鱼和违规网捕，采用农业农村部渔政执法举报受理平台作为全国入口。全国热线为 **010-59191110**。微信用户可搜索“中国渔政”公众号，进入举报功能。湖北随州先觉庙水库电鱼案有该平台将群众线索移送属地查办的记录。[农业农村部、公安部通知](https://www.agri.cn/zx/hxgg/202605/t20260506_8833435.htm) · [农业农村部公报案例](https://www.moa.gov.cn/nybgb/2022/202205/202206/P020220616319546469813.pdf) · [苏州市农业农村局公众号指引](https://www.suzhou.gov.cn/szsrmzf/bmwj/202412/6c9adeb3cee443e2808f538ab61b654a.shtml)

**现阶段的用户流程**

1. 用户在水域地图选点，填写时间和事实。点“上报”后，钓友集保留一份个人记录，提示用户到对应的官方渠道完成提交。
2. 有已核实的属地涉渔网上收件表单时，优先给出该入口。例如上海市农业农村委允许填写事发区域、违法事实并上传图片或 PDF。全国渔政渠道仍可在页底找到。其他地区可复制文字材料，在“中国渔政”举报入口按要求提交附件。[上海市农业农村委行政执法举报信箱](https://nyncw.sh.gov.cn/jb/index_zf.html)
3. 长江流域涉嫌非法捕捞等犯罪线索另有公安部公布的专用邮箱。用户选用后，邮箱预填收件人和文字材料，用户添加原始附件并确认发送。[公安部公布的长江大保护举报渠道](https://cjjjd.ndrc.gov.cn/gongzuodongtai/bumendongtai/202309/t20230901_1360306.htm)
4. 其他水域问题按职责分流。河湖侵占、岸线等水利问题可在水利部 12314 官网填报。违法排污、水体污染可在生态环境部平台在线举报并查询进度。[水利部 12314](https://supe.mwr.gov.cn/#/) · [全国生态环境投诉举报平台](https://jubao.mee.gov.cn/)

**实现应用内直接送达所需的官方对接**

在本次核对的部委文件、官网和公开办事入口中，尚未查到对个人主体小程序开放的全国涉渔举报提交、附件上传或回执查询接口。可通过农业农村部渔业渔政管理局办公电话 **010-59193366** 咨询平台运营及对接联系人。[机构职能与联系方式](https://yyj.moa.gov.cn/jgzn/)

可向对方询问“钓友集是个人主体微信小程序，用户可提供事发水域坐标、时间、事实描述和原始影像。请问是否接受第三方在举报人确认后代传线索？如可接入，烦请告知申请主体要求、联调联系人、坐标系、附件格式和大小，以及收件回执和状态查询方式。”

取得正式授权后，在新项目的服务端对接。用户确认收件单位和本次发送的内容后再发送。以每笔上报的唯一编号防止重试造成重复投递，按官方规范传送坐标和原始附件。取得官方收件回执后显示“已送达”和外部编号，收到受理反馈后显示“已受理”。遇到网络中断、结果待确认时先凭编号查询。若全国平台只接受机构合作，可先与愿意接收线索的市县渔政部门试点，按其书面确认的收件方式对接，覆盖该部门的辖区。

## 位置与排序

联系方式收在“上报”按钮下方。目录按所选水域的省市区匹配，同一辖区内可核实的办公地点，按距所选水域的直线距离排序。有事发城市电话区号时可向用户提供当地 12345 转办热线。

高德查询只发送公开机构名称，不发送私人材料。必须精确同名、同市、同区且只有一个匹配结果，才采用高德返回的办公点坐标；找不到或存在歧义时保留辖区排序，不显示猜测距离。机构名称/电话仍以官方来源为准。没有收集到的地方机构不会被地图中同名商铺补入目录；目录尚非全国全部管理处覆盖。

## 邮件

“发送邮件”先要求本机当前账号补齐称呼、联系邮箱；邮箱资料不是已验证的SMTP发件账号。设置和渠道页复用同一个资料表单。

资料齐全后展示具体收件单位、邮箱及将带入的内容，用户打开自己的邮件应用，选择发件账户并确认发送。使用标准mailto预填收件人、主题和文字材料；不伪造From，不附私密附件签名URL，不承诺自动添加原片。图片、视频需在邮件中添加。小程序不能直接唤起系统邮箱时给出复制邮箱/材料的操作说明。退出、换号、切记录会清除未完成的邮件动作。

此流程不能确认外部邮件发出或官方受理，因此不会将“已私密保存”自动改成“已送达”。

## 设计依据与验收边界

Apple `buttons.md`、`layout.md` 用于动作对齐与稳定触区；`entering-data.md` 用于在必要时补充邮箱，`lists-and-tables.md` 用于当地机构优先；`accessibility.md` 用于大字与键盘。UI UX最初的Python系统入口不可用，随后使用本机uv安装的Python：根任务的 `consistent button size touch target` 查询命中Touch Target与Font Size Scale；官方入口补充查询收窄后只命中标签溢出、输入标签等一般规则，动作文案采用Apple `buttons.md › Content` 的明确目的原则，不把无关检索项当作依据。

- `tests/report-channel-location.test.ts`：辖区/距离/精确POI匹配/未知距离/过期来源。
- `tests/report-mail-message.test.ts`：编码、收件人/联系资料/正文、无伪造发件人与附件、拒绝换行注入。
- `scripts/test-report-email-channels.mjs`：真实H5组件，隔离GPS、POI、API和邮件adapter，3组通过。320/375/440、横屏、宽屏、深色大字及邮箱表单/确认框实际截图已查看。结果在`artifacts/report-email-channels/`。
- 未触发真实拨号、邮件、上传或官方举报；系统邮箱关联与真机能力仍需设备验收。

- [最高检公布12309官网及公益诉讼线索入口](https://www.spp.gov.cn/spp/zdgz/201909/t20190917_431888.shtml)，[2026年意见继续要求优化12309网上服务](https://www.spp.gov.cn/xwfbh/wsfbt/202603/t20260326_724756.shtml)。H5可请求打开已公布的 `https://www.12309.gov.cn/`，微信端复制网址到浏览器；属于公益损害线索入口，不能把它说成所有涉渔问题的即时处置渠道。工具直接访问官网返回403，未据此宣称已经登录或提交官方表单。

上述小程序来源没有公开可核实AppId、页面路径或URL Link，因此真实目录不包含猜测的直达数据。按照[uni.navigateToMiniProgram官方文档](https://uniapp.dcloud.net.cn/api/other/open-miniprogram.html)，仅有经官方来源核实的AppId时，微信端才可使用打开分支；目前展示的是准确的名称复制与进入指引。H5不伪造微信深链，不把公众号改称小程序，也不加入已停止服务的旧12369入口。

`tests/report-channel-entry.test.ts` 验证类型、辖区、平台分支与无猜测AppId；`scripts/test-report-official-entries.mjs` 使用真实H5组件、拦截剪贴板与外部打开动作，验证准确名称/URL、六种布局，不执行真实举报。截图在 `artifacts/report-official-entries/`。
