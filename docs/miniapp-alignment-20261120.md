# 小程序图标与文字对齐

本轮只收尾图文对齐及检查中发现的地图弹层遮挡，完成后按用户要求暂停小程序优化。不是全项目或真机验收结论。

## 实现

- 微信的组件样式隔离挡住了部分复合组件传入 `MobileAction` 的局部样式。地点行、个人资料卡、皮肤选项、文章内容、地点选择行、好友选择、线索记录和聊天卡片在自己的模板内渲染原生按钮，继续复用 Pro 的 `.mobile-action`、图标和键盘处理。保留按钮名称、禁用状态、焦点和原有业务动作。
- 单行图标与文字居中，多行列表以文字组居中，长提示对齐首行。地点文字占剩余宽度，箭头留在行尾；不使用页面级负边距或逐个图标的像素补丁。
- 公共地图选择器的实现归属 `supabase-mobile-pro/packages/mobile-core/src/components/MobileMapChooser.vue`。按钮局部样式落在原生节点上；弹层位于底部导航上方，避免遮住“复制地点”。生成的 `_mobile-core` 由同步脚本更新。
- 同轮修复普通页面标题的空插槽、登录与账号页容器的盒模型，以及 WXSS 不支持的重复全局通配选择器。

## 依据

已使用本仓库 Apple Design 与 UI UX Pro Max 技能。Apple 的布局、按钮、字体、无障碍和弹层参考用于稳定行框、触区、换行和关闭行为；Pro 的 `.agents/references/mobile-alignment.md` 明确说明微信样式隔离下的原生按钮组合方式。本轮保留既有皮肤和排版，不增加装饰或业务功能。

## 验证范围

- 微信开发者工具实际截图：钓友圈、找钓位、消息、我的、设置、登录、发布页折叠/展开及上下段、鱼情详情、钓位详情、聊天。证据位于 `artifacts/miniapp-acceptance`，其中 `manual-pages` 为逐页截图；超时的批量运行不计通过。
- H5 独立本机体验回归：六个页面 × 六种环境（320、375、440、横屏、宽屏、深色150%文字），另检查皮肤键盘选择、焦点、地图弹层关闭及焦点返回。量测图标盒与文字行框中心，同时人工查看截图。输出位于 `artifacts/h5/alignment-*`。
- 原生 WXSS 使用安装的微信编译器检查；类型检查与构建结果单独保存，不代替视觉验收。
- 全量旧 `smoke-h5 --visual-audit` 的后续表单断言仍包含旧字段名，未宣称整套通过。本轮独立使用 `--alignment-contract` 检查改动范围。

以上交互使用明确标注的本机体验数据，不发送真实短信、聊天或上报，不证明远端登录、GPS、上传或物理手机行为。合法域名同步与其余小程序页面验收留待恢复任务后继续。

## 收尾结果

- 类型检查通过；最终 H5 对齐合同 37 项通过，其中地图弹层新增实际命中测试，确认底部导航没有覆盖“复制地点”。`artifacts/miniapp-alignment-h5-contract.log` 保存结果。
- 体验包及正式配置小程序包构建完成；正式包 27 路由的本地分包检查通过，77 份 WXSS 的微信原生编译通过。标准输出已更新到 `dist/build/mp-weixin`。
- `artifacts/miniapp-acceptance/final-feed.png`、`final-settings.png`、`final-map-sheet.png` 为最终样式的微信模拟器截图。最后一张地图弹层由组件事件打开供视觉核验；实际点按、遮挡命中、Escape 和焦点返回在 H5 验证，不把此截图算作小程序触摸测试。
- 本轮图文对齐与地图弹层收尾完成；后续小程序优化按用户要求暂停。未宣称全部页面、全部业务或物理手机已验收。
