## 公开发布前仍需处理

1. **境外处理与接收方信息。** 核实本项目合同项下的实际境外接收方名称、联系方式、处理目的、方式、信息种类、权利行使渠道及分包处理情况。主区域是爱尔兰，但云端函数、内容分发、支持及日志可能涉及其他地区；当前客户端没有固定 Edge Function 区域，不能承诺全部数据仅在爱尔兰处理。结合实际数据类型、规模和适用条件评估出境路径、影响评估、告知与单独同意等要求；普通登录勾选框不自动替代这些义务。是否迁移境内服务需要另行决策，不能靠改文案解决。
2. **保存期限与清理制度。** 按账号资料、业务内容、图片、关系与消息、登录及安全记录、举报与审核记录、缓存和备份分别确定保存期限或确定方法，并落实删除、到期清理和备份轮换。仓库当前没有完整可验证的保存制度，不编造7天、30天或180天等期限；用户页现有用途说明不能替代应有的保存期限告知。
3. **删除边界及端到端验证。** 当前动态与钓位删除主要为状态删除；日志删除不代表其关联图片自动被清理。限流记录、审核记录与账号的删除关联和到期规则仍须逐项核实；孤立存储对象的周期清理尚未实现。注销函数先清图片，再删除认证账号并依赖关系清理业务数据，图片处理失败不得提示注销完成。需以真实账号验证各类数据、所有图片分页、聊天双方历史、失败重试及备份边界，不将契约测试当成远端删除证明。
4. **短信登录未就绪。** 阿里云短信只是拟选路径，尚未接入，不应列为已接入第三方，也不能仅打开 phone provider 开关就宣称完成。该路径需要通过 Supabase Send SMS Hook 或经确认的适配实现发送，并完成服务端部署、签名/模板与密钥配置、失败处理、限流和真实短信验收；当前未部署该桥接、未配置相关密钥。验证码首次登录、已有账号登录和注销前身份复核均需真实链路验收。短信供应商确定后再补全用户告知和第三方清单。阿里云官方当前说明个人认证账号的个人自用资质不能完成普通国内短信签名实名报备，试用100条不能解决该资质要求；无企业资质的个人开发者可另行评估号码认证服务（PNVS）的短信认证，但它不是普通SMS产品，额度不能默认通用，计费与适配需分别确认。本次没有替用户更换产品、开通付费服务或购买套餐。

## 面向用户的措辞边界

- “不分享位置”限制对外展示，不等于服务端从未保存选点坐标。
- 删除好友、拉黑或清理本机草稿，不等于删除既有云端聊天；别人已保存的照片或截图无法追回。
- 删除内容不等于立即清除全部关联记录或备份；注销应按实际清理结果提示，不许承诺瞬时彻底删除。
- 公开与好友可见的动态、钓位接受内容审核；不能把私人日志写成进入同一审核队列，也不能暗示所有聊天经过自动审核。
- Supabase、高德以及微信原生地图使用的腾讯底图是实际功能涉及的服务提供方。2026-11-24用户确认微信原生地图＋高德搜索，应用内位置说明已区分小程序腾讯底图与H5/Capacitor高德地图，平台隐私表单也须按这份实际实现核对。第三方说明不替代钓友集的告知及保护责任。
- 上述未决事实不能被“正式文案已完成”或删除内部措辞掩盖。上线前应让运营者与适当的法律专业人员核对实际制度和要求。
