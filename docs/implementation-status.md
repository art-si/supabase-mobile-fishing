1. **真实用户流程：** 已有临时真实 Auth 用户的上传、好友、聊天、上报与权限API证据；仍缺真实短信会话、审核员、成功注销，以及三端实际界面的完整端到端证据。
2. **个人微信主体：** 已按确认方案实现短信入口 + 高德地点搜索／静态预览，禁用 `getPhoneNumber` 与 `web-view`。社交、UGC、通信相关类目和审核资格仍须在微信后台核实。
