# 鱼形视觉系统

日期：2026-11-19。范围：H5 启动等待、三端内容加载、空状态、首页与登录品牌、鱼情记录、默认头像、钓友圈底栏、设置版本区，以及小程序头像和原生品牌资源。

## 设计判断

钓友在水边打开应用，主要工作是读鱼情、找钓位、记录和聊天。通用工程原有的蓝色方块、旋转圈及“工作台”文案缺少钓鱼社区的身份。最终以用户最后确认的图形为准：圆润鱼身、内凹且尾尖收圆的尾巴、下方收圆的聊天小尖角、三颗聊天点和一只眼睛。不添加写实鱼鳍、鳃线，也不采用抽象环形，精修只调整轮廓与细节的协调。

唯一几何源为 `assets/brand/fish-symbol.svg`（viewBox 160 × 96）。H5 启动内联同一 SVG，不依赖外部图片或应用 JavaScript 下载；三端 `FishMark` 使用从该 SVG 导出的主题 PNG 分层，CSS 只负责尺寸和动效，不另画一条鱼。

识别点是同一条鱼在不同功能里的状态：加载时轻摆尾、吐气泡；空列表静止停在水纹上；消息空状态是两条相向的鱼；鱼情记录用微型鱼标识鱼种。列表、搜索、导航和弹层保持已有的使用方式。

方案自审：单纯给通用旋转圈换绿色仍然缺少身份；整页铺鱼纹会降低内容可读性。将同一鱼形放在品牌身份、真实等待与空状态等有明确用途的位置，图形大小随角色变化，正文和控件继续使用现有组件。钓友圈底栏保留文字与选中语义，其他导航仍使用熟悉的功能图标。

## 颜色与文字

复用 `src/domain/appearance.ts` 的语义调色板，鱼形跟随湖畔青、深海蓝、岩石灰及系统深浅色。

| 角色 | 湖畔青日间 | 湖畔青夜间 |
| --- | --- | --- |
| 页面背景 | #F5F7F5 | #111C19 |
| 内容面 | #FFFFFF | #1A2822 |
| 正文 | #182D27 | #EAF2EE |
| 辅助文案 | #53665F | #A4B6AE |
| 鱼形与主动作 | #0F6B5B | #79CEB8 |
| 少量浮漂信号 | #914C2D | #E7AE8D |

沿用 Noto Sans SC / 系统字体；标题 28px / 700，正文 16px，状态文案 14px，数据等宽。所有文字使用 rem，保留换行和大字布局。

按 sRGB 相对亮度计算，正文 / 辅助文案 / 鱼形对页面底色的对比分别为：日间 13.51 / 5.68 / 5.96:1，夜间 15.31 / 8.21 / 9.41:1。水纹和小气泡为装饰，状态由独立文字说明。

## 结构与动效

```text
紧凑屏                         宽屏
鱼形 钓友集      记录            [居中的 600px 阅读区]
搜索 / 推荐 关注 同城            鱼形 钓友集       记录
                               搜索 / 推荐 关注 同城
    小鱼  正在读取鱼情…           小鱼  正在读取鱼情…
正文逐条进入                     正文逐条进入
钓友圈 找钓位 消息 我的            钓友圈 找钓位 消息 我的
```

加载只在实际等待时出现，完成即移除，不额外延迟启动、不显示虚构百分比。鱼身仅移动少量像素，尾部轻摆，外围小气泡用透明度和位移提示仍在工作。空状态、品牌、导航和设置鱼标静止；三颗聊天点与眼睛属于固定标识，不作为进度点。系统“减少动态”关闭鱼身、尾部及气泡动画；文字始终独立说明状态。

H5 启动屏使用内联样式、SVG 和原生 HTML，颜色跟随系统并读取已保存皮肤。应用完成挂载后自然替换。iOS / Android 原生启动资源也从同一 SVG 导出为静态图，保留现有画布尺寸和平台启动行为，不人为延长启动；H5 内的等待状态可在 Capacitor 中复用。

## 实现归属

Pro 的 MobileLoadingStatus、MobileEmptyState、MobileTopBar、MobileListFooter、MobileBottomNav 提供通用命名插槽，保留默认外观。鱼形、场景、启动内容和业务使用均放在本仓库。`src/_mobile-core` 只通过既有同步命令生成。

`scripts/generate-brand.mjs` 从同一 SVG 导出 24 张 640 × 384 的主题分层 PNG（三种皮肤 × 明暗 × brand/muted × body/tail），并导出 Logo、小程序头像、H5 图标、Android / iOS 安装图标与静态启动资源。完整路径与尺寸见[品牌图像](brand-assets.md)。初始 imagegen 原稿、提示词及后续预览稿保留作历史参考，不混入生产几何源。
