# 资料与选择交互验收

设计按项目 Apple Design 的 entering-data、pickers、images、accessibility 参考，以及 UI UX Pro Max 的表单与触控规则审查。以下是项目内部验收，不表示 Apple 官方认证。

## 操作规则

| 场景 | 当前交互 |
| --- | --- |
| 我的 → 编辑钓友资料 | 点击头像，从相册或相机选择；调整位置、缩放、旋转后使用；可恢复默认头像 |
| 常驻城市、同城切换、地点搜索城市、钓位所在城市 | 同一个城市选择器；按省份点选或输入即筛选；可选字段能清空，旧值保留到主动修改 |
| 喜欢的钓法、发布钓法 | 复用同一多选组件及预设，支持自定义；个人资料最多 6 项、合计 40 字 |
| 钓位常见鱼种 | 使用发布页的鱼种多选与自定义入口 |
| 钓位费用 | 选择未核实、免费、收费提示，或补充自己的说明；不推测真实价格 |
| 钓位核实日期 | 日历选择，沿用统一日期控件 |
| 上报省市区 | 共用城市组件的区县模式，在一个弹层逐级选择 |
| 昵称、简介、鱼情正文、地点关键词 | 保留自由输入；不把个人表达和搜索词替换成虚构内容 |

头像是候选上传，点击「保存资料」才成为当前公开头像。裁切或上传期间禁止保存；取消裁切不上传。保存失败保留本次编辑并复用已上传图片。离开未保存的页面可选择继续编辑；同一账号重新登录保留编辑，切换账号清除旧内容。

保存后的头像由个人主页、我的、动态作者和钓友／会话列表共用。图片读取失败显示默认头像。重复出现的同一头像只申请一次签名；签名不会写回资料表。

## 数据与远端

- 城市 393 项、区县 3478 项，来自固定的 `@vant/area-data@2.2.0`（2025 年版名称）。这是选择建议，不声明覆盖每次最新行政调整。
- `node scripts/update-region-options.mjs` 离线重建；旧的 city/district 生成入口转调该脚本。区县仅存 `[id,name,cityId]`，省市名称复用城市表，生成器逐项验证展开结果。MIT 许可保存在 `src/domain/data/area-data.LICENSE.txt`。
- 头像使用已消除原图元信息的图片上传；私有候选不能被访客签名。`update_profile.avatar_id` 省略时保留，显式 null 恢复默认。只能关联自己的未绑定图片，不能把视频或正文／钓位／消息／线索附件作为头像。
- 远端迁移 `20261120102300_fishing_profile_avatar` 及 `20261120102600_fishing_avatar_visibility` 已回读。替换后旧图不能再取得新签名，已有短期签名仍可能在到期前使用；旧图由现有删除队列清理。拉黑关系同时约束新的头像签名。

## 验收证据

- `artifacts/profile-avatar/`：H5 真实裁切画布、拖动／触屏／键盘改变像素、旋转与 JPEG 输出；接口隔离，未冒充远端上传。
- `artifacts/city-profile/`：城市选取、多选钓法、定位失败回退、晚到定位不覆盖手选、清空与保存失败。
- 检查 320、375、440、横屏、宽屏、深色及 200% 字号，实际查看截图；触控操作为至少 44px。
- `artifacts/profile-db-final.log`：777 项 PostgreSQL 检查及 22 项删除队列检查；与真实远端验证分开记录。
- `artifacts/profile-unit-complete.log`：218 项单元检查通过。修复了测试凭据与模拟时钟跨秒导致的边界误判；子进程的冷启动有界等待调整为 15 秒，未放宽业务校验。
- `artifacts/profile-avatar-remote.log`：确认项目上 12 项实际 Auth／上传／资料／Storage 检查。只使用 3 个临时邮箱确认账号，不发邮件或短信。账号、会话、对象和限流测试记录均已回读清理。
- `scripts/test-profile-build.mjs` 可服务固定隔离构建；设置 `PROFILE_BUILD_DIR=dist/build/h5` 可验正式产物。共享 Pro 的 3 个消费者分别执行类型检查、隔离 H5 构建与浏览器回归。
- `artifacts/profile-avatar-accepted.log`：最终正式 H5 产物 7 组头像／表单交互通过，含空白昵称就地提示、聚焦和不提交；`profile-production-ui-final.log`、`profile-regions-production-ui.log` 分别记录城市／钓位及省市区／上报联动。截图已实际查看。

微信构建、包体检查和 Capacitor 网页资源同步单独记录。Windows 端没有用编译成功代替 iOS／Android／微信真机相册、摄像头、键盘和手势验收；这些设备检查仍需在对应设备完成。
