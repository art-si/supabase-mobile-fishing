# 发布、地图与资料交互更新

2026-11-20。当前规则以本页和对应实现为准；其他文档保留的圆形提醒、排序弹层、鱼情待审核描述属于此前版本。

## 当前行为

- 新建统一进入“记录鱼情”，渔获与心得共用表单，通过分享范围选择公开、好友或仅自己。我的页面不再另放“记一次出钓”入口；“我的记录”也读取已有私人出钓日志，不迁移或公开旧日志。旧链接和旧日志编辑保留兼容。
- 鱼情保存即发布；作者可以从列表直接编辑并在原记录重新发布。原帖 ID、创建时间、点赞和评论保留。公开范围、作者权限、媒体归属、版本冲突和重试幂等由服务端继续检查。钓点与禁钓上报流程未在本次鱼情直发中改变。
- Pro 公共 `MobileMediaUploader`、`MobileMediaGallery`、`MobileImagePreview` 和 `MobileVideoViewer` 统一选择、展示与预览。混合缩略图等宽等高，详情保留真实比例；视频从真实内容读取封面，解码失败提供重试，不生成示意帧。右上角关闭、离页暂停与焦点恢复一致。
- H5 附件直接拖动交换位置，触屏长按后拖动，键盘使用 Alt+方向键。移除按钮有独立圆底和48px触区，调整顺序不会重启上传或丢失进度。
- 日期、时间与心得主题使用公共主题选择器；时间弹层的取消、确定按钮沿用已有操作样式。
- 同城与资料共用城市选择器，支持全国离线选项、搜索、按省浏览和定位。同城首次进入尝试定位，手动选择优先；只筛选常驻该城市的钓友分享，不自动修改个人资料。省直辖城市、旧名称省略“市”的匹配已处理。资料钓法与发布多选一致。
- 头像可选择、裁剪、旋转、更换或恢复默认，与资料同次保存。保存失败保留候选；头像只能使用本人经过服务端验证的图片，与帖子、聊天和私密线索附件互斥。替换后旧对象进入既有清理队列。
- 线索上报使用同一套省市区选择器。新表单尝试填入真实行政地区、详细地点和当前时间；已有草稿、手动输入及离页会使迟到定位失效。定位失败仍可手选。最多6项图片或视频，勾选私密保存同意前不上传；保存不代表已发给外部单位。
- 地图搜索浮在地图上方、占满可用宽度，首个结果高亮并立即定位；下拉各项有位置图标。加载在地图视口居中，原下方天气、提示、位置按钮区移除。地图本体和围栏绘制在 Pro `MobileMap` 中复用。
- 禁钓范围改为可点击的多边形，详情显示地理位置、描述及来源。快速连续圈点不会被地图双击识别丢弃。范围按当前全国视口读取，不绑定武汉政策。
