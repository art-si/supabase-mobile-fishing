# 线索上报与动作对齐

2026-11-20。目标是从记录现场到整理材料、选择官方入口的一条完整流程，沿用现有皮肤和公共控件。

## 已实施的规则

- 新建空表单一次定位，填入同一位置的省市区、地点和坐标，事发时间取当前设备本地时间。只有自动默认值的旧草稿不再带回旧地区和时间；有内容或明确修改的草稿保留。编辑已存事件保留原事发信息。
- “发布上报／我的上报记录”使用既有公共页签。记录可以查看、编辑原 ID、删除；失败保留输入，版本冲突重新读取前不会覆盖远端。删除应用材料不撤回已在外部发送的内容。
- 保存前仍需确认私密云存储说明。新建与各条编辑草稿按账号隔离；定位和请求迟到不得覆盖手动输入或其他账号。
- 记录与材料详情均使用公共紧凑附件网格，单张也占一个缩略格。点击沿用公共图片／视频全屏预览，保留关闭和焦点返回。
- 渠道优先匹配事发辖区，再对可精确匹配的同级机构计算距本次当前位置的直线距离。没有可靠位置时不展示猜测距离；没有收集到的机构不冒充全国完整覆盖。
- 个人联系邮箱按账号保存在本机，退出清除；设备邮件应用负责选择真正的发件账号与最终发送，图片视频需另行添加。外部入口打开不改变“私密保存”为“官方受理”。

## 公共视觉修复

Pro `styles/actions.scss` 提供 `.mobile-action-group`：同一组按钮共享字号、列宽、触区与垂直居中，窄屏或大字按可用空间纵排。钓友集 `.text-action` 修复文字停在按钮上沿的问题。新公共类已应用于上报渠道、上报记录、发布管理、旧日志、好友操作、静态地图、围栏操作及通知动作；聊天输入行等不同结构保留自己的布局。钓友列表和主页中多余的 `>` 文本已删除。

Apple `buttons.md › Style` 使用同尺寸、以样式表达层级；`entering-data.md › Best practices` 用于自动默认值；`collections.md › Best practices` 用于简单等宽缩略网格。UI UX查询 `consistent button size touch target` 命中 Touch Target Size、Font Size Scale，沿用现有48px移动触区和字号，不添加新颜色、装饰或动效。
