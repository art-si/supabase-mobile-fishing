# 小程序包体与分包

2026-11-20。这里记录本地构建检查，**不是微信上传包分析或真机验收**。

## 实现

- 保留原有27个路由地址和全部页面文件。首页、登录、三个账号页、设置、协议共7页在主包；其他20页按原目录分为10个普通分包。没有独立分包、异步跨包引用或全量预下载。
- 四个底部入口仍由原首页承载；分包不改变导航、登录目标恢复、权限、草稿、审核状态或任何业务数据。旧地图桥接地址仍转到地点搜索，不引入个人小程序 web-view。
- `src/pages.json` 使用标准JSON。当前安装的 Uni 编译器在 H5 合并这些路由；Capacitor继续使用该H5产物。分包声明与优化方式参考[DCloud页面配置](https://uniapp.dcloud.net.cn/collocation/pages.html#subpackages)和[分包优化说明](https://uniapp.dcloud.io/collocation/manifest?id=optimization)。没有套用独立分包或其他版本的编译能力。
- Pro 的 `global.scss` 增加可选参数 `$embed-body-font`，默认仍为true。只有钓友集的 `MP-WEIXIN` 构建显式关闭内嵌中文字库，使用系统字体栈；图标字体保留。H5、Capacitor和其余Pro消费者保持原样，不下载远程字体。
- 默认Pro样式在改动前后均为1,192,880字节，SHA-256均为 `81bb3ce35b66673b4f1cb6a29e4584874c68bb060480335e4028d3b82c654967`。新增测试还逐项确认除正文font-face和字体栈外的样式一致。

## 自动检查

```powershell
pnpm build:mp-weixin
pnpm check:miniapp
pnpm exec tsx --test tests/miniapp-package.test.ts
```

正式小程序构建后自动执行检查，`release:check`也直接重读产物，不依赖旧的成功报告。

- 检查源配置与构建配置的全部路由、主包页及分包根目录一致；禁止重复、路径越界、嵌套根目录与分包tab页。
- 检查页面JS/JSON/WXML齐全，静态`require`、WXSS导入、WXML导入与组件引用存在；禁止主包引用分包实现、普通分包引用其他分包实现。
- 当前产物1525处静态引用通过，其中27处是Uni编译器生成的不可达页面入口锚点，不是运行时跨包引用。仅精确识别`app.js`中`Math||(...)`的编译模式并核验对应已声明页面；普通`require`仍受跨包限制。测试覆盖“同一锚点之后追加真实跨包require”必须失败。
- 主包／单个分包采用 **1.5 MiB原始文件** 的项目预算，总目录采用10 MiB项目预算，为后续内容留余量。**这些是本项目自定阈值，不是对微信当前上传额度的声明**；微信官方文档本次抓取失败，正式上传规则需以开发者工具／公众平台为准。
- 这是静态引用检查，不是完整JavaScript执行分析，也不能证明动态资源URL、网络域名、权限弹窗或真机字体渲染正确。

报告写入忽略提交的 `artifacts/miniapp-package/result.json`，含原始字节数、路由数、font-face摘要、依赖数和产物摘要哈希，不含密钥或用户内容。改动前报告保留为 `baseline.json`。最终正式产物摘要：`2ad3c9f09c5c0a037d7a97c8ffbfbe8d338cda01a6492c43e7b6ca6b224d75c3`。

- 钓友集类型检查、H5／体验H5／微信构建通过；Android/iOS网页资源同步通过，不代表原生包编译或真机。
- Pro司机／货主／SMIS三个消费者类型检查、H5和微信构建通过，输出在各自 `dist/codex-package-check/`，没有覆盖原`docs`发布目录；这些消费者默认样式未改变。
- 7项新增Node检查通过。全量182项按序重跑通过；首次并行全量有1项原有账号证明时效测试偶发失败，保留这一风险，不修改账号实现或降低断言。
- 正式H5地图21组交互契约回归通过；SDK、位置与API为明确隔离样例，不代表真实GPS或小程序地图服务。
- 最终体验H5 **119项**检查通过，包含原有流程、三皮肤、深色、横屏／宽屏、键盘焦点及全部27个原路由；系统字体替代逐页检查375常规与320px的24px根字号。正式H5通知 **58项**隔离契约回归通过，没有修改线上记录。命令：`node scripts/smoke-h5.mjs --visual-audit --package-routes`、`FISHING_H5_URL=http://127.0.0.1:5181 node scripts/test-map-interactions.mjs`及同环境的`node scripts/test-comments.mjs --notifications`（PowerShell请用`$env:FISHING_H5_URL`设置变量）。
- 路由与系统字体替代的浏览器检查采用编译H5，不能冒充微信渲染。字体替代只在测试页面注入，从实际MP产物读取字体栈，并断言确实生效；小程序设备字体、胶囊安全区、键盘及分包弱网下载仍需实测。
- 实际查看首页、发布、设置及地点搜索的常规／深色大字截图。320px大字截图发现地图页标题孤字换行，改为「地点搜索／选择地点」，保留高德说明；最终两个状态都有单行断言与截图。首次字体替代测试只覆盖`:root`未覆盖Uni的`uni-page-body`作用域，断言阻止了虚假通过；修正测试注入后全量重跑，没有改生产H5字体。旧`failure.png`不是成功证据。
- 当前660个构建文件未发现高德服务端安全码；H5产物只包含一份原正文font-face，微信AppID与确认值一致。局域网5179、预览5181保持`0.0.0.0`监听，局域网HEAD200。手机浏览器定位仍需HTTPS和用户授权。
- 本轮没有修改线上Supabase、Auth、短信、地图凭证、审核员或用户数据。正式发布仍需既有人工验收，未绕过任何标志。

## 仍需设备验收

用微信开发者工具导入 `dist/build/mp-weixin`，核对AppID和包分析结果，再在iOS/Android微信验证：首次冷启动、直接打开分包页、离线后首次进入未下载分包、返回重进、登录后目标恢复、长文本与大字、三皮肤明暗、图片选择和设备键盘。

个人小程序的真实高德地点搜索／静态预览仍需要服务端 `AMAP_WEB_SERVICE_KEY`；复用的Web JS Key不应替代它。正式地图域名、隐私声明和个人主体可用权限需在公众平台核验。不要把本地分包检查当成平台审核通过。
