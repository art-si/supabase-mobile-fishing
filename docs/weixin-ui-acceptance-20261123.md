## 已修正的实现

- 头像编辑、城市、省市区、钓法、表情、日历、时间、分享范围、媒体操作、搜索清空、资料和业务行按钮：需要父组件局部样式的按钮改为在所属组件内渲染原生按钮，保留禁用、读屏和键盘行为。避免微信组件样式隔离使同行内容散开。
